Approve dependency updates

Dependabot and Renovate PRs are low-stakes and many. Today each one needs Quick Review, which waits until every file is marked reviewed. This adds one-click Approve on a dependency PR's row and an Approve dependency updates sheet that approves a batch at once, safest updates picked by default. Every approval keeps the app's rule: it waits for Undo before GitHub hears of it.

Rules

What counts as a dependency update

The author is a dependency bot: dependabot or renovate, with or without [bot] (GraphQL and REST spell it differently). Nothing else: a human's PR that bumps a package still goes through Quick Review.

Title / bodyRead as
Bump lodash from 4.17.20 to 4.17.21one package, from → to (any build(deps): prefix, any in /dir suffix)
Update dependency serde to v1.0.219Renovate: the target from the title, the current version from the body's `a` → `b` table
Bump the minor-and-patch group with 3 updatesa group: members from the body's "Updates `x` from a to b" lines, sized by its largest jump

How big the jump is

  • Semantic versions compared part by part: major, minor, patch. A 0.x minor is a minor: the repository's checks catch a breaking one.
  • Anything we can't read (dates, git refs, a group without its list) is unknown and never picked by Safe.

Safety

  • Each approval names the commit you saw (commit_id), and is sent only if the PR's head is still that commit. Auto-merge is enabled with the same expected head.
  • Approvals wait five seconds for Undo, like Quick Review's. GitHub can't take a review back.
  • Batches run one PR at a time. GitHub throttles bursts of writes; a few dozen in a row is fine.
  • Merge when checks pass uses the repository's merge method. If the repository doesn't allow auto-merge, the approval stands and the summary says so.

Not in this change

  • Other bots and a configurable bot list. Two names cover what you have today.
  • A Focus card for dependency updates. The strip is in the PR list only.
  • Asking the bot to rebase a conflicted PR (@dependabot rebase).

BorgDock Review for iPhone

A second iPhone app that does one thing: show which pull requests need you and make reviewing them pleasant. It reads GitHub and Azure DevOps from the phone itself, with no BorgDock server in between. Sample data is the made-up acme shop.

Decided

  • A second app, for review only. The overview, a pull request, Quick Review, the work item behind a PR, and setup. Nothing else.
  • No server. The phone talks to GitHub and Azure DevOps with your own tokens, kept in its keychain.
  • Only what GitHub and Azure DevOps give. No agents, T3 threads, Fix with Claude, push notifications, Sprint, Work or Notes.
  • It looks like BorgDock. BDTokens and BDComponents, iOS 26 Liquid Glass, light and dark.

Overview: three directions

Overview: three directions

The same sixteen pull requests in each: six reviews asked of you (one is a re-review after new commits), three of your own that need something, two ready to merge and five waiting on others. The directions differ in what the first screen gives up: A puts the review run first, B gives every bucket equal room, C shows everything at once.

A

Queue

The first screen is the review run itself: the pull request Start review opens, then the rest in the order you'll get them. Your own pull requests follow, grouped by what they need.

My recommendationThe app has one job, and A is the only direction where the order of the run is visible before you start it. The cost (your own pull requests are a scroll away) is covered by the three pills under the title.
Best atStarting in one tap, and knowing what you'll read first and what comes after.
CostsYour own pull requests start below the fold when the queue is longer than three.
From today's appFocus's "6 reviews wait for you" card and its Your turn list become one thing: the queue, in run order.
B

Board

Four counts stay on top and the list shows one lane at a time. A lane has room to say why on every card: the failing test, the reviewer's words, the question.

Best atTriage. Your own pull requests get as much room as the reviews, and you can read the reason without opening anything.
CostsOne lane at a time: seeing what's ready to merge is a tap away from the review queue. Six reviews need scrolling.
From today's appThe Pull requests tabs (Your turn, Mine, Ready) become four lanes with fixed meanings, and the card stays as it is.
C

Ledger

Everything on one screen. Two-line rows with checks, size and age in columns you can read down, like the desktop's table.

Best atThe whole picture in one look, and comparing rows: which is red, which is big, which is old.
CostsLong titles are cut off, the reason shrinks to two words, rows are 50 points high, and Start review is a small button at the top, away from your thumb.
From today's appThe desktop's table display, brought to the phone. Today's iPhone list has nothing this dense.

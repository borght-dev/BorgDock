BorgDock reads titles, state and description with your ADO token. You can still open the item in the browser.

Open Settings Ctrl+Click ADO

How it behaves

  • Opens after 300 ms, stays open while the pointer is on the link or the card, closes 150 ms after it leaves both. Esc closes it.
  • Data comes from the work item cache Dispatch and the Work Items section already fill; a miss fetches one item and caches it for the session.
  • Description is HTML-stripped plain text, clamped to 4 lines (Repro Steps for bugs when Description is empty).
  • Chips show only what BorgDock already knows: linked PRs with their check state, T3 threads with their status, child task progress.
  • Card uses --color-modal-bg so it stays opaque in light mode; the left stripe is the ADO type colour.
  • Same card replaces the plainer peek on LinkedWorkItemBadge, so every AB# looks the same.

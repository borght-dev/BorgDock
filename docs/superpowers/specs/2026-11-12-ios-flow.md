## Contract additions (shared/src, Model/*.swift)

All new fields are optional on the wire so an older server still decodes.

### File categories: `PrFile.category`

`'source' | 'tests' | 'generated' | 'docs'`, computed on the server by `server/src/github/file-category.ts`. The desktop's
`reviewFileCategory` / `isGeneratedPath` (`src/BorgDock.Tauri/src/services/quick-review.ts`) get the same patterns.
Missing on the wire → `source`.

- **tests**: `__tests__/`, `test/`, `tests/`, `*.Tests/`, `*.test.*`, `*.spec.*`; folders ending in `Tests`, `UITests`
  or `Testing` (`BorgDockTests/`, `Common.UI.Testing/`); everything under `e2e/`; `fixtures/`, `__fixtures__/`,
  `test-fixtures/`, `__mocks__/`, `.storybook/mocks/`; `*.stories.*`; `loadtests/` (but `loadtests/reports/` is generated).
- **generated** (checked before tests for snapshot folders): lockfiles (`bun.lock(b)`, `package-lock.json`,
  `pnpm-lock.yaml`, `yarn.lock`, `Cargo.lock`, `*.lock.json`, `Package.resolved`, `Podfile.lock`); `generated/`,
  `*.generated.*`, `*.g.cs|ts|dart`, `*.min.js`, `*.js.map`, `*.css.map`, root or top-level-project `dist/` and `obj/`;
  `*.snap`, `__snapshots__/`, `*-snapshots/`; `src-tauri/gen/`; `*.Designer.cs`; `*.pbxproj`; `loadtests/reports/`.
  A file GitHub sends no patch for (binary) and whose extension is wasm, png, jpg, gif, webp, pdf, ico, woff(2), ttf
  is generated too.
- **docs**: `docs/`, `doc/`, `documentation/`, `*.md`, `*.mdx`, `*.rst` (read in the walk after the source files).

### Repositories: `GET /api/github/repositories`, `PUT /api/github/repositories/preferences`, `PUT /api/desktop/repositories`

```ts
export type PrRepositories = {
  /** Where the list comes from: the linked desktop, the server's config, or nothing yet. */
  source: 'desktop' | 'config' | 'none';
  /** The desktop that sent it, and when. */
  desktopName: string | null;
  updatedAt: string | null;
  repositories: { name: string; open: number; polledAt: string | null; ok: boolean; error: string | null }[];
  /** Also read PRs that involve you in any repository (involves:@me, review-requested:@me, reviewed-by:@me). */
  includeInvolving: boolean;
  /** Count your teams' review requests (review-requested:@me) rather than only yours (user-review-requested:@me). */
  includeTeamRequests: boolean;
  /** The last full read, and whether any search hit GitHub's cap. */
  polledAt: string | null;
  cutOff: boolean;
};
```

The desktop link (Rust `phone_link.rs`) sends `PUT /api/desktop/repositories { repositories: string[] }` with its
session token whenever its watched repositories change and once after linking. The server searches each repository
on its own (`is:open is:pr archived:false repo:o/r`), paged to the end, with the account that can read it.

### Item detail: markdown, history, every PR, attachments, comments

```ts
export type ItemDetail = {
  // …existing plain-text fields stay for older apps…
  /** The rich-text fields as GitHub-flavoured markdown. Images point at signed /api/items/:id/attachments/… URLs. */
  markdown?: { description: string; acceptanceCriteria: string; reproSteps: string; qaNotes: string; developerNotes: string };
  comments: { id?: number; by: string; at: string; text: string; markdown?: string }[];
  /** Newest first, from the item's revisions. */
  history?: ItemHistoryEvent[];
  /** Every pull request linked to the item (ADO links and AB# mentions), its own first. */
  pullRequests?: ItemPullRequest[];
  parent?: { id: number; title: string; typeName: string } | null;
  effort?: number | null;
  areaPath?: string | null;
  attachments?: { name: string; url: string; size: number | null }[];
};
export type ItemHistoryEvent = {
  at: string; by: string;
  kind: 'created' | 'state' | 'assigned' | 'pullRequest';
  from: string | null; to: string | null;
  /** For kind 'pullRequest': the PR number linked. */
  pullRequest?: number | null;
};
export type ItemPullRequest = PullRequest & { repository: string | null; own: boolean; shared: boolean; author: string | null; updatedAt: string | null };
```

- `GET /api/items/:id/attachments/:guid?name=…&exp=…&sig=…`: the server fetches the ADO attachment with its own
  credentials and streams it. The URL is signed (HMAC, expires after a day), so `AsyncImage` loads it without a header.
- `POST /api/items/:id/comments { text }` → `{ comment: ItemDetail['comments'][number] }`. Posts as you; the text is
  markdown (ADO's comments API with `format=markdown`). Not signed, like PR comments. It never changes a state.

## Shared iOS pieces (foundation commit)

- `GitHubMarkdown(_ markdown:, size:)` (`Features/Markdown/GitHubMarkdown.swift`): the one renderer for PR bodies,
  PR comments, review bodies and ADO rich text. Relative image URLs resolve against the server.
- `AgentRow(thread:, detail:)` (`DesignSystem/AgentRow.swift`): status dot, title, one line, T3 pill. The row's tap is
  the caller's; the pill opens T3.
- `JumpBar(items:, selection:)` (`DesignSystem/JumpBar.swift`): the sticky chip row over a one-page screen.
- `AppModel.openThread(_:)`: PR → item → T3.

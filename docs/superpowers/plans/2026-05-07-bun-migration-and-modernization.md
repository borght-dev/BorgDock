# Bun Migration & Frontend Modernization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace npm with bun across the entire BorgDock repo, unify both projects under a bun workspace, drop the `tsx` dev dep, slim the manual `optionalDependencies` block, enable the React Compiler, and add lefthook pre-commit checks — all in one PR.

**Architecture:** Single bun workspace at the repo root (`/package.json` + `/bun.lock`) with `src/BorgDock.Tauri/` and `site/` as workspace members. CI swaps `actions/setup-node` for `oven-sh/setup-bun@v2`. React Compiler is enabled by adding `babel-plugin-react-compiler` to `@vitejs/plugin-react`'s babel plugins. Lefthook runs biome + tsc on staged files via a `postinstall` hook.

**Tech Stack:** bun 1.3.10, React 19 + React Compiler, Vite 8, Vitest 4, Storybook 10, Tauri 2.11, Astro 5, Biome 2, Playwright 1.59, lefthook 1.7.

**Spec:** `docs/superpowers/specs/2026-05-07-bun-migration-and-modernization-design.md`

## Task 7: Add Lefthook Pre-Commit Hooks

**Why this task:** Catch lint and type errors locally before the user pushes. Free CI cycles, faster feedback. The `lefthook` devDep was already added in Task 2's root `package.json`; now we configure and install it.

**Files:**
- Create: `/lefthook.yml`

- [ ] **Step 1: Create `/lefthook.yml`**

Write at `/Users/koenvdb/projects/borgdock-bun/lefthook.yml`:

```yaml
# Lefthook pre-commit checks. Run with `bunx lefthook run pre-commit` to test
# manually. Bypass for emergencies with `LEFTHOOK=0 git commit ...`.
pre-commit:
  parallel: true
  commands:
    biome:
      glob: "src/BorgDock.Tauri/src/**/*.{ts,tsx,js,jsx,json}"
      run: cd src/BorgDock.Tauri && bunx biome check {staged_files}
    typecheck:
      # tsc has no per-file mode; we run the whole project. The glob just
      # gates whether the hook fires at all when relevant files are staged.
      glob: "src/BorgDock.Tauri/src/**/*.{ts,tsx}"
      run: cd src/BorgDock.Tauri && bunx tsc --noEmit
```

- [ ] **Step 2: Re-run `bun install` so the `postinstall` hook wires lefthook into `.git/hooks/`**

```bash

bun install
```

Expected: postinstall runs `lefthook install`, which writes a pre-commit hook to `.git/hooks/pre-commit` (or to the worktree's hooks directory — git worktree hooks live under `.git/worktrees/<name>/hooks/` or fall back to `.git/hooks/` depending on git version).

- [ ] **Step 3: Verify the hook is installed**
